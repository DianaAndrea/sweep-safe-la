## **SweepSafe \- Design Guidelines (Web Version)**

### **Visual Style**

* **Tone:** Trustworthy, lightweight, local-first

* **Color Palette:**

  * Sky Blue (alerts \+ highlights)

  * Asphalt Grey (backgrounds)

  * Caution Yellow (warnings)

  * White and soft neutrals for contrast

* **Fonts:**

  * Inter, Roboto, Helvetica Neue, sans-serif (web-optimized system font stack)

  * Clear, medium-weight headlines

  * Small body text optimized for mobile readability

* **Icons:**

  * Heroicons, Lucide, or Font Awesome

  * Map pins, car icons, street sweepers

### **Page Layout Principles**

* **Mobile-First Design:** Primary layout optimized for mobile viewports

* **Responsive Grid/Flex Layouts:** Ensure clean adaptation across screen sizes

* **Map-Centric Home Screen:** Full-width map with floating card UI

* **Sticky Panels:** Parked location info remains visible

* **Minimalist Settings UI:** Collapsible menus or drawer-style interactions

### **Accessibility and Mobile-First**

* High contrast UI with large tap targets

* Screen reader support using ARIA labels and roles

* Responsive font scaling using rem/em units

* Dark mode supported by default

* Touch-friendly gestures for all interactive elements

### **Brand Tone/Voice**

* Friendly but direct

* Avoid clutter or excess jargon

* Local-first: occasional LA-style flavor in alerts (e.g., "Heads up — your side’s up next")

* Transparent about what the app can/can’t guarantee
